页面说明

每个页面有哪些区域、对应的样式类和元素 ID。改界面时可以直接说「改 XX 页的 XX 区」。

共用部分（每个页面都有）

区域类名 / ID说明
顶栏.topbar页面顶部固定栏，含品牌、导航、用户区
品牌标题.brand左上角「⭐ 小星星积分计划」，点击回今日打卡
导航菜单.nav / 当前页 a.active今日 / 周视图 / 月视图 / 存折 / 兑换 / 图表 / 说明 / 管理
汉堡按钮.nav-toggle手机端菜单开关，展开时顶栏加 .open
用户区.userbox小朋友切换下拉 .child-switch、用户名 .who、退出 .logout
提示条.flash（.flash-ok / .flash-error）操作结果提示，4 秒后自动淡出
页面标题区.page-head左侧 h1 标题 + 灰色说明，右侧统计标签
统计标签.chip（余额 .chip-balance、得分 .chip-score）余额的 <b> 有 id="balance"，打卡后自动更新
卡片容器.card白色圆角卡片，页面上大多数内容块都用它
按钮.btn（主要 .btn-primary、描边 .btn-ghost、危险 .btn-danger、小号 .btn-small）全站按钮样式
内容区.container主体内容，桌面最大 1120px 居中

今日打卡（/，模板 today.html）

区域类名 / ID说明
日期与星期.page-head 左侧当天日期 + 星期
今日统计#today-total #today-count今日得分 / 完成项数，打卡后自动更新
任务卡片.task-grid 里的 .task-card点击打卡；完成态 .done，勾选圈 .task-check，分值 .task-value
近 7 天条.strip 里的 .strip-day每天得分 .strip-score，今天高亮 .today；得分格有 data-strip-total

周视图（/week，模板 week.html）

区域类名 / ID说明
翻周按钮.week-nav上周 / 本周 / 下周

本周得分 / 完成天数#week-total #week-days合计行；每行小计挂 data-task-score / data-task-days
每日合计data-day-total合计行每天的分数
